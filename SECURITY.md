# Security policy (prototype)

MatchSphere is an **unsecured client-side demo**. There is no production account or private-message service. Please do **not** enter real passwords, sensitive identity information, or personal messages into this prototype.

The GitHub repository owner should enable private vulnerability reporting and establish a contact point before a live launch. Do not post exploit details or sensitive information in public issues. For launch blockers see [`docs/launch-checklist.md`](docs/launch-checklist.md).
