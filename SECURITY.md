# Security notice

MatchSphere is an **18+ native dating app concept**, not a public dating service. The site is marketing only and collects no waitlist submissions. The native Expo app contains fictional users, local demo requests, fictional conversations, and example safety controls. Its age checkbox is **not proof of age**, and its blocking/reporting controls are **not server-enforced**. Never use it for real personal information.

Production blockers: independent privacy-conscious age assurance, verified authentication, server-authorized mutual consent for every message read/write, operational blocking/reporting and moderation, abuse prevention, data deletion/retention, security reviews, and app store/privacy compliance.

To report a security issue, contact the repository owner privately rather than posting sensitive details in a public issue. Do not disclose account credentials or identity documents here.
