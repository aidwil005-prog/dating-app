# Native iOS/Android principles

- The dating app is iOS + Android exclusively, built with React Native/Expo. Marketing pages are not dating flows.
- Never add web as an Expo target; `/app/` browser dating screens are retired.
- Provide accessible native touch targets, readable dark text on pastels, keyboard-aware messaging and screen reader labels.
- Mock profiles, community memberships, local chats, blocks and reports are clearly illustrative and must never be framed as real or secure.
- Before release, require independent 18+ age assurance, real authentication, server-verified mutual messaging consent, genuine moderation, and privacy controls.
- Keep platform store links inactive or marked unavailable until actual listings exist.
