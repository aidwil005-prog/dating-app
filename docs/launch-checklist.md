# MatchSphere — Production Launch Checklist

- [ ] Independent 18+ age eligibility checks (not just self-declared DOB)
- [ ] Verified sign-in and account recovery
- [ ] Secure server and private data storage
- [ ] Server-side mutual approval before any message
- [ ] Server-enforced blocking, reporting and rate limits
- [ ] Spam, fake-profile and scam detection with human review
- [ ] Privacy policy, community rules, relationship-status transparency
- [ ] Location precision and discoverability controls
- [ ] Media upload scanning and moderation
- [ ] Data access, export, deletion and retention workflows
- [ ] No ads inside private chats; clear sponsor labeling elsewhere
- [ ] Independent accessibility, security and abuse testing
- [ ] Disclosure of demo content and heuristic matching
- [ ] Observability, backups and incident response
- [ ] Test with adult users, gather voluntary feedback, make no unsupported compatibility claims

None of these items should be assumed complete because a control appears in the prototype UI.
