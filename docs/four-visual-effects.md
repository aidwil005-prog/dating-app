# Four visual effects — MatchSphere

Four **original HTML/CSS/JS adaptations** inspired by the user-provided Framer links: glass footer, animated path, Polaroid shuffle, and coral-inspired organic accent.

- Footer is a purely visual glass panel. No newsletter form was added because no consentful subscriber backend exists.
- Path draws only if the browser supports IntersectionObserver and motion is allowed; otherwise it remains visible.
- Polaroids show three fictional illustrated cards and can be shuffled using an accessible button. Without JavaScript, all cards remain legible.
- Coral-inspired pastel SVG is purely decorative with subtle desktop pointer parallax. The supplied coral page was not retrievable, so this is an interpretation rather than a visual reproduction.

All code is locally authored. No Framer components, licensed source code, runtime libraries, user tracking, or remote image imports were used. MatchSphere is a marketing-only site; dating remains exclusive to an unreleased iOS/Android native prototype. `/app/` is not restored.
