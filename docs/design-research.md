# MatchSphere — Design Research and Rationale

- [The Attachment Project study](https://www.attachmentproject.com/research/psychology-dating-apps-study/) examines multiple motives for using dating apps. Its cross-sectional self-report associations are not causal proof and should not be used to diagnose people.
- [InAppStory design psychology](https://medium.com/@inappstory/the-psychology-of-mobile-app-design-how-colors-fonts-and-layouts-impact-app-perfomance-9a2e0f39e1d9) discusses typography, color and layout design. Its guidance suggests testable hypotheses, not proven universal conversion effects.
- [Apple Design Skill](https://github.com/dickwu/apple-design-skill) inspires a disciplined review process and accessibility principles.

## MatchSphere translation
Use clean type, dark navy/violet/blue accents, understated warmth and obvious navigation. Show stated intentions and shared interests before ornamental 3D effects. Reveal matching rationale as a heuristic. Facilitate respectful community conversations. Honor privacy, consent, no deceptive profiles, accessibility and optional motion.

The existing interface is an illustrative prototype. It is not a real matchmaking service; no relationship success should be inferred from compatibility numbers.
