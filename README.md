# MatchSphere — Website + App
Two separate, linked experiences in one repository.

- [Marketing website](/) — editorial peach-and-blush landing page, with features, stories and phone mockups.
- [Interactive app](/app/) — distinct pastel discovery dashboard, matches, communities, consent-based demo messages, profiles, safety and onboarding.
- [Standalone website source](/website/) — marketing directory for an independent static deploy.

The website links to /app/#onboarding; the app has return-to-website links in its header/sidebar/footer. To deploy separately, use Vercel rootDirectory "website" and "app" in two projects and update cross-domain links if the domains change.

These are **18+ fictional demos**. Profiles, messaging, ratings and communities are simulated; no production AI matching, secure auth, age verification or moderation backend exists. Do not accept real user data until independent age assurance and server-side safety checks exist.
